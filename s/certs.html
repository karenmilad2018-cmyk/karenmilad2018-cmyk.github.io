Notes from practice

What I check before I design

01

Check the names once in the Excel list, not on the certificates. One correction there fixes every certificate.

02

Give each certificate a number and a date, so it can be verified later.

03

For Arabic names, use a font that supports Arabic and set right-to-left, or the names print broken.
